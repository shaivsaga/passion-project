# passion-project
A Notion-esque to-do list website for my classmates who struggle to keep up with schoolwork.

Features

To-do list: Due date, Status (not started, in progress, done), Comment, Notes (allow images), a “Done” overview, Visual Display of a Calendar, and data stored locally.
Personal To-do list: Same features as the public To-do list, but no comments, and it’s only for yourself.
Settings (QOL): View your to-do list snapshot, transfer your data, reset all data, and a chatbot on messaging platforms that messages and notifies you of your to-dos in (x) time before the due date (in which x can be set periodically in intervals).
